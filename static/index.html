Live Ingestion API

Send logs in real-time from any server

Push a single log event

curl -X POST http://<your-server>:8000/api/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "timestamp": "2026-09-19T04:00:00",
    "client_ip": "1.2.3.4",
    "method": "GET",
    "url": "/admin",
    "status_code": 403
  }'

Nginx integration (one-liner)

tail -F /var/log/nginx/access.log | \
  python3 simulate_live_server.py

Python SDK snippet

import requests
requests.post(
  "http://localhost:8000/api/ingest",
  json={"timestamp": ..., "client_ip": ...}
)
